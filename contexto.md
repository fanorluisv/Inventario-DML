# Proyecto: Gestión de Inventario LICENCIAS DML

## Resumen del Proyecto
Este proyecto tiene como objetivo desarrollar una aplicación web para administrar activos y licencias de TI. Por decisión de Fanor Vivas del 2026-09-10, las fuentes de trabajo son `ACTIVOSTI.md` y `LICENCIASDML.md`. El administrador del proyecto es Fanor Vivas. Por decisión expresa del 2026-09-10, ACTIVOSTI es el centro de la aplicación; las licencias sirven para identificar en qué equipo están asociadas.

## Arquitectura
- **Frontend**: Vite + React + TypeScript. Ubicado en `/frontend`.
- **Backend**: Node.js. Ubicado en `/backend`.
- **Base de Datos**: SQLite para la primera versión en un único servidor. Esquema inicial definido en `backend/db/schema.sql`; aún sin importación conciliada.
